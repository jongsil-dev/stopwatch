# 티켓팅 시계 (실시간 시계 + 초시계)

아이폰에서 티켓팅할 때 다른 앱을 켜 두고도 `시:분:초.밀리초`를 볼 수 있는 웹앱입니다.
단일 HTML 파일 하나로 만들어졌고, 외부 라이브러리·CDN·유료 API를 쓰지 않아 인터넷이 없어도 동작합니다.

## 쓰는 방법

1. 아이폰 사파리에서 아래 주소를 엽니다.
   - https://jongsil-dev.github.io/stopwatch/
2. 하단 공유 버튼 → **홈 화면에 추가**를 누릅니다.
3. 홈 화면의 **티켓팅 시계** 아이콘으로 앱처럼 실행됩니다. (주소창 없이 전체 화면)

## 기능

### 실시간 시계 (기본 탭)
- **현재 시각 `HH:MM:SS.cc`** — 0.01초 단위까지 고정폭(tabular-nums) 숫자로 크게 표시, 오늘 날짜·요일 함께 표시
- **목표 시각 카운트다운** — `다음 정각` / `10:00` / `14:00` / `20:00` 칩 또는 직접 입력(`HH:MM`)
  - 남은 시간을 `HH:MM:SS.c`로 표시
  - 마지막 10초부터 카운트가 빨갛게 강조되고 1초마다 신호음, 0초에 도착 알림음 + 화면 강조
  - 목표는 기기에 저장되어 앱을 다시 열어도 유지(지난 목표는 자동 정리)
- **작은 창(PiP, 화면 속 화면)** — 버튼 한 번으로 실시간 시계가 작은 창에 떠서 다른 앱·사파리 다른 탭을 쓰는 동안에도 계속 돌아갑니다. (아이폰은 iOS 15.4 이상 사파리 필요)
  - 캔버스를 **640×150(약 4.3:1) 초슬림 미니 비율**로 만들어, 화면에서 차지하는 면적을 이전 16:9 창의 절반 이하로 줄였습니다.
  - 창 안에는 `HH:MM:SS.cc` 숫자만 캔버스 높이에 꽉 차게 그리고, 목표 카운트다운을 걸면 남은 시간이 오른쪽에 한 줄로 붙습니다(마지막 10초는 빨강). 맨 아래에 얇은 진행 바.
  - `<canvas>`(640×150)에 매 프레임 시각·카운트다운을 그려 `captureStream(30)` → `<video>`로 연결
  - iOS Safari `webkitSetPresentationMode('picture-in-picture')` 와 표준 `requestPictureInPicture()` 모두 지원
  - PiP가 막히는 기기·브라우저에서는 이유와 해결 방법을 화면에 안내

### 초시계 (두 번째 탭)
- **0.01초 단위 측정** — `performance.now()` 기준이라 탭을 바꾸거나 화면이 꺼져도 시간이 밀리지 않습니다.
- **버튼** — 시작 / 일시정지 / 계속 / 초기화 / 랩
- **구간 기록** — 랩마다 구간 시간과 누적 시간, 가장 빠른 구간(▲)과 가장 느린 구간(▼) 표시, 기록 복사
- 키보드: Space 시작/일시정지, L 랩, R 초기화

### 공통
- **다크 / 라이트 모드** — 기본은 다크, 선택은 기기에 저장
- **효과음** — Web Audio로 만든 짧은 소리, 켜기/끄기 (선택은 기기에 저장)
- **화면 꺼짐 방지** — 시계·측정 중에는 화면이 자동으로 꺼지지 않게 요청
