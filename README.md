# 초시계 (Stopwatch)

아이폰 홈 화면에 추가해 앱처럼 쓰는 0.01초 초시계 웹앱입니다.
단일 HTML 파일 하나로 만들어졌고, 외부 라이브러리·CDN·유료 API를 쓰지 않아 인터넷이 없어도 동작합니다.

## 쓰는 방법

1. 아이폰 사파리에서 아래 주소를 엽니다.
   - https://jongsil-dev.github.io/stopwatch/
2. 하단 공유 버튼 → **홈 화면에 추가**를 누릅니다.
3. 홈 화면의 **초시계** 아이콘으로 앱처럼 실행됩니다. (주소창 없이 전체 화면)

## 기능

- **0.01초 단위 측정** — `performance.now()` 기준이라 탭을 바꾸거나 화면이 꺼져도 시간이 밀리지 않습니다.
- **버튼** — 시작 / 일시정지 / 계속 / 초기화 / 랩
- **구간 기록** — 랩마다 구간 시간과 누적 시간, 가장 빠른 구간(▲)과 가장 느린 구간(▼) 표시, 기록 복사
- **다크 / 라이트 모드** — 기본은 다크, 선택은 기기에 저장
- **효과음** — Web Audio로 만든 짧은 소리, 켜기/끄기 (선택은 기기에 저장)
- **화면 꺼짐 방지** — 작동 중에는 화면이 자동으로 꺼지지 않게 요청
- 키보드: Space 시작/일시정지, L 랩, R 초기화
